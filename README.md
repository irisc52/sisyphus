Anti-Doomscrolling iOS app

Demo Video: https://www.youtube.com/watch?v=NJQ1NKt1kKM  

Summary:

An iOS app that makes doomscrolling physically exhausting: the longer you scroll, the harder it gets. After your time limit, scrolling slows down, pages go greyscale, and the domain is eventually blocked for the day.

Features:

- Progressive scroll resistance - Gets harder the more you scroll
- Custom time limits and domains
- Analytics dashboard - Track time wasted, how many domains being blocked
- 24-hour reset: fresh start every day

Installation:

1. Install Xcode on macOS
2. Create a new app project or use Safari Extension template
3. Add this extension: File → Add Files to Project → select the sisyphus folder
4. In Xcode: Product → Scheme → Edit Scheme → set run destination to your iPhone
5. Connect your iPhone to your device and on your phone, turn on Developer Mode in Settings
6. Build and run on device
