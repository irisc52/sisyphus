Anti-Doomscrolling Chrome Extension
Demo Video ( add link) | Install (add link)

An iOS app that makes doomscrolling physically exhausting: the longer you scroll, the harder it gets. After your time limit, scrolling slows down, pages go greyscale, and the domain is eventually blocked for the day.

Features

Progressive scroll resistance - Gets harder the more you scroll
Custom time limits and domains
Analytics dashboard - Track time wasted, how many domains being blocked
24-hour reset - Fresh start every day
Installation

Install Xcode on macOS
Create a new app project or use Safari Extension template
Add this extension: File → Add Files to Project → select the sisyphus folder
In Xcode: Product → Scheme → Edit Scheme → set run destination to your iPhone
Connect your iPhone to your device and on your phone, turn on Developer Mode in Settings
Build and run on device
